0# روبوت تتبع المسار المستقل المتطور (Autonomous Line Follower Robot) - نسخة الـ 12 حساس 🏎️

روبوت سباق متطور وعالي السرعة لتتبع المسار، يعتمد على قوة معالج **ESP32-S3** ومبرمج بالكامل بلغة **C++** عبر بيئة **Arduino IDE**. يدمج الروبوت أحدث أنظمة التحكم الذكي (PD Control) مع نظام رؤية محيطي هجومي يعتمد على 12 حساس (TCRT5000)، بالإضافة إلى حسابات الملاحة والتوازن الفوري عبر حساس MPU6050.

---

## 🚀 الميزات البرمجية والخوارزميات (تحديث V2.0)

* **خوارزمية التوجيه التناسبي التفاضلي (PD Control):** خوارزمية محسنة تعمل على الـ 8 حساسات المركزية (S3 إلى S10) لحساب نسبة الانحراف بدقة عالية وتعديل توجيه المحركات بشكل سلس وسريع، مع استثناء الحساسات الطرفية لمنع التشويش عند التقاطعات.
* **المعايرة اللاسلكية الذكية (Strategy 0):** نظام آلي مدمج لمعايرة قراءات الأبيض والأسود للحساسات الـ 12. يقوم النظام بذكاء باستثناء الرادارات الطرفية (S1, S2, S11, S12) لحساب متوسط لون دقيق بنسبة 100%، ويولد مصفوفات برمجية جاهزة تلقائياً عبر بث الـ Telnet.
* **الذاكرة الزمنية للرادارات (Radar Time Memory):** نظام استكشاف جانبي يعتمد على الحساسات المتطرفة (S1, S12) والداخلية (S3, S10) لاكتشاف المنعطفات الحادة (90 درجة) والتقاطعات قبل وصول العجلات إليها، مما يمنح الروبوت رد فعل استباقي بأجزاء من الثانية.
* **مواءمة السرعة مع المنحدرات (MPU6050 Slope Handling):** قراءة زاوية الميلان الرأسي (Pitch) ومضاعفة السرعة وتوجيه المحركات تلقائياً عند صعود المرتفعات (زاوية > 10) لتجاوز الجاذبية، أو خفضها للنصف عند النزول (زاوية < -10) لمنع الانزلاق.
* **التحديث والتصحيح اللاسلكي (OTA & Telnet Dashboard):** إمكانية رفع الأكواد عبر الهواء ومراقبة قراءات الحساسات وتعديل قيم `Kp` و `Kd` والسرعات المختلفة (Base, Max, Turn) حياً أثناء ركض الروبوت في الحلبة.

## 🛠️ المواصفات الهندسية والأبعاد الفيزيائية

* **الوزن الكلي:** 425 غرام.
* **قاعدة العجلات (Wheelbase):** 70.00 ملم (المسافة الطولية بين مركز العجل الأمامي والخلفي).
* **عرض المحور الخلفي:** المسافة بين مركزي العجلتين الخلفيتين 87.50 ملم (العرض الخارجي الكلي 108.50 ملم).
* **عجلات الدفع:** قطر 33 ملم بعرض 19 ملم.
* **المحركات:** محركات DC ذات تروس (Geared DC Motor) بجهد 12V وسرعة قصوى 1000 RPM.
* **السرعة الخطية القصوى:** حوالي 1.728 متر/ثانية.

### 📐 الهندسة الدقيقة لجناح الحساسات (12x TCRT5000)
تم تصميم الجناح الأمامي للحساسات بعرض هجومي إجمالي يبلغ **145.5 ملم**، والمسافة الكلية بين مركزي S1 و S12 تبلغ **139.7 ملم**. التوزيع المليمتري مقسم إلى 3 مناطق استراتيجية:
1. **الكتلة المركزية الكثيفة (8 حساسات S3 إلى S10):** مسافة 7.62 ملم بين كل حساس (3 ثقوب) لضمان أعلى دقة لخوارزمية الـ PD.
2. **فجوة الإنذار المبكر (S3 مع S2 / S10 مع S11):** مسافة 17.78 ملم (7 ثقوب) لتهيئة الروبوت للمنعطفات.
3. **فجوة رادار المنعطفات الحادة (S2 مع S1 / S11 مع S12):** الفجوة الأكبر بمسافة 25.40 ملم (10 ثقوب) لإعطاء أمر الفرملة العكسية المبكرة قبل خروج الروبوت عن المسار.

* **تفعيل الدرايفر (STBY):** GPIO 48 (HIGH للتشغيل)

## ⚙️ الإعدادات الحرجة في برنامج Arduino IDE

لاستغلال القوة الكاملة للوحة **YD-ESP32-S3 (نسخة N16R8)** يجب ضبط التالي قبل رفع الكود:
* **Board:** `ESP32S3 Dev Module`
* **Flash Size:** `16MB (128Mb)`
* **PSRAM:** `OPI PSRAM` (لتفعيل الـ 8 ميجابايت إضافية).
* **USB CDC On Boot:** `Enabled` (للسيريال المدمج).
* **Flash Mode:** `QIO` (سرعة نقل مضاعفة 4 مرات).
* **Flash Frequency:** `80MHz`.
* **Partition Scheme:** `8M with spiffs (3MB APP/1.5MB SPIFFS)` لدعم الـ OTA.

## 📡 دليل المعايرة والتحكم اللاسلكي الحي عبر Telnet

### خطوات المعايرة الدقيقة (الاستراتيجية 0)
1. اضبط مفاتيح DIP على `000` وافتح (PuTTY / Termius) عبر IP الروبوت.
2. ضع الروبوت فوق **اللون الأبيض** واضغط Limit Switch (يأخذ 100 قراءة متجاهلاً الرادارات الطرفية).
3. انقل الروبوت للـ **الخط الأسود** واضغط مجدداً ليحسب عتبة الفصل (`lineThreshold`).
4. انسخ كود المصفوفات الجاهز المطبوع في التلنت والصقه في الكود الرئيسي.

### لوحة التحكم الحية (Live Tuning)
أثناء عمل الروبوت، أرسل هذه الأحرف عبر الكيبورد لتعديل الأداء دون إعادة البرمجة:
* `q` / `a` : زيادة / تقليل المعامل التناسبي `Kp` بمقدار 0.1.
* `w` / `s` : زيادة / تقليل المعامل التفاضلي `Kd` بمقدار 0.1.
* `e` / `d` : زيادة / تقليل السرعة القصوى `maximumSpeed` بمقدار 25.
* `r` / `f` : زيادة / تقليل السرعة الأساسية `baseSpeed` بمقدار 25.
* `t` / `g` : زيادة / تقليل سرعة الانعطاف `turnSpeed` بمقدار 25.
* `0` إلى `7` : التبديل الفوري بين استراتيجيات السباق.
